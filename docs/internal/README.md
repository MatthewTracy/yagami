# Internal project materials

These files support maintainers; they are intentionally excluded from the
published documentation navigation.

- [`contributor-backlog.md`](contributor-backlog.md) contains issue-ready work
  with file paths and acceptance criteria.
- [`adoption-runbook.md`](adoption-runbook.md) lists account-side publication
  and repository-discovery steps that code cannot safely perform on its own.
- [`launch/`](launch/README.md) contains outreach drafts. Do not publish those drafts
  until the release gate in `launch/README.md` is satisfied.
